# Library Management System (Python CLI)

*A simple command-line Library Management System built using Python. This project allows users to add books, view available books, issue books, and return books.*

## Features
- Add new books
- Display available books
- Issue books
- Return books
- Simple menu-driven interface

## Technologies Used
- Python 3

## Project Structure
library.py → Main program containing all functions

## How to Run
1. Install Python 3
2. Download or clone the project
3. Open terminal in the project folder
4. Run:
   python library.py

## How It Works
- books → stores available books
- issued_books → stores borrowed books

Menu Options:
1. Add Books → Add a book to the library
2. Show Books → Display available books
3. Issue Books → Borrow a book
4. Return Book → Return a book
5. Exit → Close program

## Limitations
- No permanent storage (data resets on restart)
- No user login system
- No database support
